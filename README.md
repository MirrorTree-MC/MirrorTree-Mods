# MirrorTree Mods

MirrorTree 自制模组源码，面向 Minecraft 26.1.2 / Fabric / Java 25。三个模块共享构建，保留各自的 mod ID、版本和存档路径。

| 模块 | 内容 | 安装端 |
| --- | --- | --- |
| [LIStorm](listorm/README.md) | 灯具防护、梦魇、探索经验、技能与默认技能树 | 客户端与服务端 |
| [Journey](journey/README.md) | 卧室、入梦往返、物品与装饰器 | 客户端与服务端 |
| [Sync Sign Notice](sync-sign-notice/README.md) | MySQL 公告标牌 | 仅客户端 |

使用发行包请阅读[安装与升级](docs/INSTALLATION.md)，包括依赖、更新工具和独立 MirrorSkills／旧技能树的处理。配置、世界、玩家数据和数据库凭据不随包分发。

开发维护从 [AGENTS.md](AGENTS.md) 开始。源码来源见 [UPSTREAM.md](docs/UPSTREAM.md)，许可证见 [LICENSES.md](LICENSES.md)。
