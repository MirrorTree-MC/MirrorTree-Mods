# 实现记录

## 结构

`LanternInStorm` 是唯一内容入口，协调注册和服务端事件；客户端由 `StormClient` 单独初始化。三个原项目直接编译为一个内容 JAR。

| 模块 | 职责 |
| --- | --- |
| `lanterninstorm/content` | 灯/物品/实体注册、方块状态、起点实体、粒子 |
| `lanterninstorm/safety` | 已加载区块灯位置索引、防护装备、安全区与耐久 |
| `lanterninstorm/progression` | 世界内玩家记录、经验计算及 Pufferfish 来源 |
| `lanterninstorm/effects` | 食物/交互限制、计时、死亡消失诅咒、清理 |
| `lanterninstorm/network` | HUD 显示/阶段同步，按玩家缓存变化 |
| `annoyingeffects/effect` | 原效果类型、属性修饰器、独立效果实现 |
| `lanterninstorm/mixin` | 原版内部的食物、进度、物理、姿态、重生调用点 |
| `src/client` | HUD、实体渲染、输入、聊天和镜头；公共代码不引用客户端类 |

## 保持的规则

- 原版命名空间维度的灯稳定范围为半径 8 的立方体；其他维度使用灯自身半径。普通木灯/玻璃灯在其他维度不能启用；金属灯半径 2/4/8/16，纪念灯为 8。
- 起点附近半径 16；入服/重生宽限 10 秒，设置入梦点宽限 80 秒。`mirrortree:bedroom` 恒定安全，不依赖灯具、装备、宽限或 API 注册；API 设置其他安全维度仍受支持。
- 手电耐久 600，灯旁每秒回充 20；原版维度不耗电，其他维度每秒消耗 1；电量耗尽保留物品供充电，防护退化为弱梦魇。护符耐久 120，每秒消耗 1，消耗后从背包补充。
- 初次清理每个有害效果消耗 2 耐久，原版维度手电免费。alpha.2 修正：其他维度中电量耗尽的玩偶停止清理效果，使梦境缠绕及其施加的负面效果正常保留；充能后恢复防护。
- 梦魇累计与弱化系数、倒数间隔权重、效果时长/等级默认值沿用本地 AnnoyingEffects ui。效果通过延迟队列加入，避免遍历活动效果时修改集合。
- Spirit 使用本地 2.0.1 经验设计，不恢复 GitHub 旧版灵魂奖励或已删除的胡萝卜铁砧彩蛋。群系/进度去重，食物/矿石递增次数保存到新世界。

## 有意调整和兼容修复

- 灯查询由每玩家扫描方块改为区块装载时建立位置索引，仅访问邻近已加载区块；卸载清理，破坏后的过期位置在查询时移除。查询不会生成区块。
- 半径是灯的固定属性，不再复制为庞大的整数方块状态；编解码保留半径。旧档不兼容属于已确认范围。
- HUD 包只在显示/阶段变化时发送；世界停止、断线及重生清理临时状态。玩家 JSON 仅脏记录需要保存时写入，使用临时文件替换。
- 末影人仇恨扫描从每 tick 调整到每 20 tick，范围保留，最多增加一秒响应时间。滑溜改为按实体修改摩擦，去除全局标志。
- 重力效果对新版流体系统保留水流推动减半、额外下沉及入水落距限制。灌水不破坏硬度为负的不可破坏方块。
- 26.1.2 食物组件统一处理原版和 Farmer’s Delight 的派；删除旧版专用派钩子，避免一口计两次经验。
- 物品模型描述、配方原料、材料依赖条件和掉落表已转换。护符混合原料列表转换为联合物品标签；修正 `promethium` 标签错拼和缺失金属方块状态，补齐粒子贴图引用。
- 可选材料模组不存在时使用原版材质回退；存在时启用内置材料资源包。材料配方需要对应模组才加载。

- alpha.2 增加新放置规则：`mirrortree:bedroom` 与所有 `starryskies:*` 维度，仅允许迈达斯金、墨菱石、星辰和钷四种神话金属灯。按灯种白名单判断，纪念灯不会因半径相同而获准。放置前拒绝，不消耗物品，不影响已有灯具的存续。

## 对外接口

`LanternInStormAPI` 保留 `setRTPSpawn`、`setWarpSpawn`、`getRTPSpawn`、`addSafeWorld`、`overrideRTPSpawnSetting` 的用途，参数更新为 26.1.2 官方名称类型。入梦点同时保存维度与坐标，避免跨维度读取错误。其他旧版二进制插件需要重新编译。

新增存档格式不读取旧 NBT/旧 JSON；新世界数据经过关闭、重新打开验证。效果 JSON 使用原文件名，已有参数保留，缺项补默认值；启用效果的间隔必须大于零。

- alpha.4 撤销 alpha.2 的灯种类放置限制；球球世界点亮防护规则不变。补齐卧室登录时已有梦魇的清理与效果 tick 防护。
