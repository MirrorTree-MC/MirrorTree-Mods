# Minesweeper Bridge

仅安装在 Fabric 26.1.2 服务端，与 MirrorTree Minesweeper 数据包配套使用。玩家无需安装客户端模组。

使用 `/minesweeper` 打开个人棋盘。按钮使用原版自定义点击数据包，服务端静默执行固定的扫雷操作，不经过聊天命令的成功回执或频率限制。每位玩家每游戏刻最多处理一个操作，重复包静默丢弃；不接收任意命令或其他玩家 ID。

棋盘与进度仍由数据包保存。数据包在没有此模组时回退到 `/trigger` 按钮；移除模组后重启即可回退，存档格式不变。模块不改变全局命令反馈规则，也不能消除公网网络延迟。

构建：从仓库根目录运行 `gradlew.bat :minesweeper-bridge:build`。只安装正式 JAR，停服、备份与回滚遵循工作区运维手册。
